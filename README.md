Projeto de Automação para o "Planejamento do Professor por Turma".

Esse Planejamento nada mais é que um roteiro pedagógico que adapta as diretrizes curriculares e a BNCC (Base Nacional Comum Curricular) às características específicas, ao ritmo de aprendizagem e às necessidades reais de cada grupo de alunos.

O script tem como objetivo acessar a plataforma, realizar a autenticação utilizando as credenciais fornecidas pelo cliente e efetuar a replicação das aulas que ainda não foram concluídas no planejamento educacional.
O planejamento é composto por oito disciplinas: Matemática, Português, Geografia, História, Ciências, Ensino Religioso, Educação Física e Artes. Cada disciplina possui uma quantidade específica de aulas a serem replicadas, variando conforme sua carga de planejamento, por exemplo, as disciplinas de Matemática e Português apresentam, em média, cerca de 20 dias letivos planejados, exigindo aproximadamente 20 replicações de aulas. As demais disciplinas demandam um número variável de replicações, geralmente entre 5 e 12 por matéria.

O fluxo de execução do script consiste em:

1- Acessar a plataforma e realizar o login;
2- Identificar as aulas pendentes de replicação;
3- Replicar o conteúdo da aula selecionada;
4- Salvar as alterações realizadas;
5- Avançar automaticamente para a próxima aula pendente;
6- Ao concluir todas as aulas de uma disciplina, prosseguir para a disciplina seguinte;
7- Repetir o processo até a finalização completa de todo o planejamento.

O tempo médio de execução do script é de aproximadamente 40 minutos para concluir integralmente o planejamento.
